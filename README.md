# Agenda Astrologia — widget rosa pastel

## O que tem aqui
- `index.html` — o widget do calendário (auto-contido, sem dependências além de fontes do Google).
- `astrologia.ics` — exportação da agenda "Astrologia". O widget lê esse arquivo direto, sem precisar de API do Google.
- `lua.ics` — calendário com as fases da lua
